Thank you [Sebastian Stern](https://github.com/Sebaestschjin/tts-tools), for making collaborating on TTS not a complete misery. 

## Getting Started
- Download [vscode](https://code.visualstudio.com/).
- Install [Sebastian Sterns](https://marketplace.visualstudio.com/items?itemName=sebaestschjin.tts-editor) VS Extension.
- Install [node](https://nodejs.org/en).

## Contributing 
- Clone this repo.
- Run ``npm install``.
- Build TTS save from unpacked files via ``npx tts-save embed unpacked -o [Chosen file name]``.
- Load up TTS and load into save. ``Ctrl+Alt+L`` to load scripts.
- Make changes. ``CTRL+Alt+S`` to save.
- Rebuild unpacked using modified save via ``npx tts-save extract [Save name] -o unpacked/``.
