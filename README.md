# Notice
I don't expect that much collaboration will take place with this mod, and as of writing, TTS tooling for collaboration is awful.

Due to the above facts, i will not be making any kind of sophisticated pipeline. The flow will be:

- Follow the 'Getting Started' to setup
- Make a change
- Send a PR with your code snippet
- I review the PR
- I merge the code into the blob in the repository

**If you would like to contribute to the mod, please follow the instructions below to set up a basic 'pipeline'.**

## Getting Started
- Download [vscode](https://code.visualstudio.com/)
- Install a TTS vscode plugin (either [Sebastian Sterns](https://marketplace.visualstudio.com/items?itemName=sebaestschjin.tts-editor) or [rolandostars](https://marketplace.visualstudio.com/items?itemName=rolandostar.tabletopsimulator-lua))
- [Subscribe](https://steamcommunity.com/sharedfiles/filedetails/?id=2243006775) to the mod
- Launch it, and whilst menu is visible, make a saved copy
- Launch into saved copy, and follow vscode plugin instructions to get scripts
- You're now free to make changes!
